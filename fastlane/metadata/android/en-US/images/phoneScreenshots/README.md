# Store Screenshots Guidelines

This directory contains phone screenshots for F-Droid and Google Play Store listings.

## Requirements

- **File Format:** PNG or JPEG
- **Image Count:** Minimum 2, maximum 8 screenshots per locale
- **Dimensions:** Any side between 320 px and 3840 px
- **Aspect Ratio:** Consistent orientation across all screenshots (e.g. 16:9, 19.5:9, or 20:9 portrait)

## Recommended Screen Capture Workflow

Capture screenshots on a physical device or emulator (e.g. 1080x2400 or 1440x3120):

1. `main_screen.png`: Main application screen displaying configured SIM cards and current minutes/traffic usage bars.
2. `widget_preview.png`: Home screen showing active MinuteWatcher widgets in dark and light themes.
3. `widget_settings.png`: Widget configuration screen with background transparency and layout settings.
4. `limit_dialog.png`: Set limits dialog for minutes and monthly traffic.
5. `about_dialog.png`: About dialog showing app details and developer information.
