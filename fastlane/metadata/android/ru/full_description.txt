MinuteWatcher помогает отслеживать остаток минут и мобильного трафика по каждой SIM-карте.

Основные возможности:
• Поддержка нескольких SIM-карт: независимый учёт минут звонков и мобильного интернета для каждой активной SIM-карты.
• Настраиваемые виджеты на рабочий стол: несколько режимов отображения (включая подробный шестистрочный вид) с регулировкой размера шрифта, цвета и прозрачности фона.
• Автоматическое отслеживание: непрерывный учёт длительности вызовов и расхода мобильных данных через системные API Android.
• Уведомление в строке состояния и на экранах Always-on Display: опциональная постоянная сводка на экране блокировки и AOD.
• Плитка быстрых настроек и ярлыки: быстрый доступ к показателям расхода прямо из шторки уведомлений и меню приложения.
• Автоматический сброс по расписанию: установка ежемесячного дня обновления для каждой SIM-карты согласно расчетному периоду оператора.
• Ручная корректировка: удобная подстройка значений при расхождении с данными оператора.
• Приватность: все данные хранятся исключительно локально на вашем устройстве. Никаких внешних серверов, аналитики и передачи данных.
• Поддержка 28 языков.

Примечание о переводах:
Интерфейс приложения переведён на 28 языков. Переводы, кроме русского и английского, выполнены машинным способом и могут содержать неточности.
